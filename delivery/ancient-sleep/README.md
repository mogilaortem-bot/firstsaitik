# Ancient Sleep — архив материалов

Готовые файлы для скачивания: [ancient-sleep-v1](https://github.com/mogilaortem-bot/firstsaitik/releases/tag/ancient-sleep-v1).

Архив содержит оригинальный MP4, звук FLAC, обложку, субтитры, сценарий, источники, все иллюстрации, восемь записей озвучки и переносимый проект сборки. Части архива нужны для хранения в Git и автоматически объединяются при выпуске.

При необходимости восстановить архив вручную:

```bash
python assemble.py .
```

Проверка SHA-256 выполняется автоматически для каждой части и полного ZIP.
