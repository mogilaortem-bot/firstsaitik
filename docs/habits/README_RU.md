# Ancient Bergman · выпуск 03

**You vs. a Human 50,000 Years Ago** — английский выпуск про пять повседневных привычек: еду, внешний вид, заботу о зубах, чужие новости и истории.

Это комплект подготовки нового ролика. Визуальные версии имеют заметную пометку **NEW NARRATION PENDING** и не содержат диктора. Для готового выпуска нужны восемь новых записей ElevenLabs.

## Что готово

- 40 отдельных новых рисунков, включая современные и древние сцены.
- Сценарий на 1104 слова, разбитый на восемь файлов без ремарок.
- Монтажный план на 150 планов, 43 основных текстовых акцента, парные сравнения эпох.
- Обложка **SAME HABITS?**, основной заголовок и описание для YouTube.
- Предварительные субтитры, источники, промпты, шрифты с лицензиями и скрипты сборки.

Плановый хронометраж — около 7:37 при расчётном темпе 150 слов в минуту. Фактический темп голоса и паузы определят итог. Первые 16 планов занимают около 36 секунд. Точное значение находится в `episode.json`.

## Озвучка

Используй тот же сохранённый голос ElevenLabs и настройки, которые уже подошли каналу. Открой восемь TXT из `voiceover/` или отдельного архива `ElevenLabs_8_Texts_EN.zip`. В каждом файле только текст для диктора.

Подача разговорная и живая. Начало — короткие фразы без длинных вступительных пауз; научные названия и числа произносить ясно; шутки — с сухой иронией, без трейлерного крика. Не добавлять музыку и эффекты в синтез речи. Не ускорять запись ради планового хронометража: монтаж будет подстроен под неё.

## Файлы

`Opening_Preview_NO_VOICE.mp4` — визуальный монтаж начала. `Full_Visual_Draft_NO_VOICE.mp4` — весь предварительный монтаж без голоса. В этих версиях показан текст диктора, чтобы оценить связь рисунков со сценарием. В финальном видео полные субтитры можно сделать отдельной включаемой дорожкой.

`STORYBOARD.md` связывает текст с иллюстрациями. `timeline_DRAFT.json` и CSV содержат все планы и движения камеры. `text_overlays_DRAFT.json` — надписи. Все таймкоды предварительные. `sources.json` и `Script_EN_with_sources.md` связывают утверждения с исследованиями и указывают границы интерпретаций.

## Повторная сборка визуального монтажа

Нужны Python 3.10+, NumPy, SciPy и FFmpeg с libx264, libass и AAC:

```sh
python -m pip install -r requirements.txt
python prepare_package.py
python render_visual.py opening
python render_visual.py full
```

Скрипт обрабатывает два плана одновременно и сохраняет промежуточный кэш в `build_visual/`. Команда `sample` рендерит выборочные планы для проверки. Голос скрипт не генерирует. Сборка финального ролика с новой озвучкой — следующий этап.

Иллюстрации созданы для этого проекта. Изображения исследований не копируются; схемы не являются фотографиями находок. Шрифты и их лицензии лежат в `fonts/`. Короткие звуковые акценты синтезируются скриптом; чужая музыка и исходные референсные ролики в комплект не включены.
