# Ancient Bergman — выпуск 02

**You Broke a Leg 30,000 Years Ago. Now What?**

Подготовлен английский сценарий, иллюстрации и проект монтажа. Для финального ролика нужна новая озвучка. Видео `Opening_Preview_NO_VOICE.mp4` — предварительный монтаж начала с надписями и звуковыми акцентами, без диктора. Это не готовый выпуск.

## Скачать и озвучить

1. Открой папку `voiceover`. В ней восемь TXT-файлов: только английский текст, без ремарок и заголовков.
2. Используй в ElevenLabs тот же сохранённый голос и настройки, которые понравились в первом выпуске.
3. Синтезируй каждый файл отдельно, без музыки, эффектов, дополнительной нормализации и изменения скорости.
4. Сохрани результат в настоящем WAV или исходном MP3. Не переименовывай MP3 в WAV — это не меняет формат.
5. Пришли восемь записей с именами ниже. По ним можно точно собрать монтаж, расставить акценты и синхронизировать субтитры.

| Текст | Имя записи |
|---|---|
| 01_one_bad_step.txt | 01_one_bad_step.wav или .mp3 |
| 02_getting_home.txt | 02_getting_home.wav или .mp3 |
| 03_the_dangers.txt | 03_the_dangers.wav или .mp3 |
| 04_the_long_recovery.txt | 04_the_long_recovery.wav или .mp3 |
| 05_shanidar.txt | 05_shanidar.wav или .mp3 |
| 06_borneo.txt | 06_borneo.wav или .mp3 |
| 07_the_debate.txt | 07_the_debate.wav или .mp3 |
| 08_finale.txt | 08_finale.wav или .mp3 |

Первые фразы произносятся коротко и собранно. В середине — живое любопытство, в конце — тепло и лёгкая ирония. Специальные теги эмоций в текст не добавлены: их поддержка зависит от выбранной модели ElevenLabs.

## Материалы

- `Voiceover_Full_EN.txt` — весь текст одним файлом.
- `Script_EN_with_sources.md` — сценарий по главам со ссылками на исследования.
- `assets/` — 24 отдельные иллюстрации; `asset_catalogue.json` сопоставляет их с 32 сюжетными позициями.
- `thumbnails/A_GAME_OVER_Upload.jpg` — основная обложка для загрузки (менее 1 МБ); исходный PNG сохранён рядом.
- `CREATIVE_BRIEF_RU.md` — драматургия, стиль, принципы текстовых вставок и оговорки по источникам.
- `episode.json` — структурированный сценарий, связанный с кадрами и надписями.
- `timeline_DRAFT.json`, `.csv`, `text_overlays_DRAFT.json`, `Subtitles_DRAFT_EN.srt` — предварительные тайминги по темпу 147 слов в минуту. После озвучки их необходимо пересчитать.
- `sources.json` — источники и границы утверждений.
- `prepare_package.py`, `render_preview.py`, `fonts/` — файлы для воспроизведения предварительного монтажа; лицензии шрифтов вложены.

Для повторного рендера нужны Python 3 и FFmpeg с `libx264`, `libass` и `drawtext`. Команды из этой папки: `python prepare_package.py`, затем `python render_preview.py`. Скрипт по умолчанию собирает только первую главу, без голоса. Сценарий, иллюстрации и пакет файлов не являются публикацией готового ролика на YouTube.
