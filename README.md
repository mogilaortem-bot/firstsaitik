## GitHub Pages

Источник публикации: ветка `main`, папка `/docs`. В **Settings → Pages → Build and deployment** выбрать **Deploy from a branch**, затем `main` и `/docs`.

После включения Pages адрес страницы:
`https://mogilaortem-bot.github.io/firstsaitik/`.

GitHub Pages обычно делает страницу общедоступной. Возможность использовать Pages для частного репозитория зависит от тарифа и настроек GitHub.
